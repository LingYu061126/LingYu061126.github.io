## 一、随机变量分布函数及密度函数的定义、关系及性质

### 1、分布函数
$F(x) = P(X \leq x), x \in R$，密度函数满足 $F(x) = \int_{-\infty}^{x} f(x)dx$，且 $f(x) \geq 0$

### 2、分布函数的性质：
- ① $\forall x_1 \lt x_2, F(x_1) \leq F(x_2)$
- ② $F(-\infty) = 0, F(+\infty) = 1$
- ③ $\lim_{x \to x_0^+} F(x) = F(x_0)$，即 $F(x)$ 右连续
- ④ $P(X = x_0) = F(x_0) - F(x_0 - 0)$
- ⑤ $P(a \leq X \leq b) = F(b) - F(a - 0)$（易错）

### 3、密度函数的性质：
- ① $f(x) \geq 0$
- ② $\int_{-\infty}^{+\infty} f(x)dx = 1$（归一化性质）
- ③ $\forall a \lt b, P(a \lt X \leq b) = \int_{a}^{b} f(x)dx$
- ④ 若 $F(x)$ 连续可导，且在 $f(x)$ 连续点有 $F'(x) = f(x)$

## 二、随机变量函数的分布

若 $Z = g(X)$，仅需解 $Z = g(X) \leq z$ 的解集 $G = \{x | a \leq x \leq b\}$，

则 $F_Z(z) = F_X(b) - F_X(a - 0)$，再对其求导即可得 $f_Z(z)$。其中 $a, b$ 一般是关于 $z$ 的一个函数。

## 三、二维随机变量的分布函数、密度函数及边缘密度、条件密度定义、关系与性质

### 1、
$F(x,y) = P(X \leq x, Y \leq y) = \int_{-\infty}^{x}\int_{-\infty}^{y} f(x,y)dxdy$，其中 $f(x,y)$ 非负

### 2、分布函数的性质：
- ① $F(+\infty, +\infty) = 1, F(-\infty, *) = F(*, -\infty) = 0$
- ② $\forall x_1 \lt x_2, F(x_1, y) \leq F(x_2, y)$；$\forall y_1 \lt y_2, F(x, y_1) \leq F(x, y_2)$
- ③ $F(x,y)$ 对 $x$ 及 $y$ 均右连续，即 $F(x+0, y) = F(x, y+0) = F(x,y)$
- ④ $P(x_1 \lt X \leq x_2, y_1 \lt Y \leq y_2) = F(x_2, y_2) - F(x_1, y_2) - F(x_2, y_1) + F(x_1, y_1) \geq 0$

### 3、密度函数的性质：
- ① $f(x,y) \geq 0$
- ② $\int_{-\infty}^{+\infty}\int_{-\infty}^{+\infty} f(x,y)dxdy = 1$（归一化性质）
- ③ $f(x,y) = \frac{\partial^2 F(x,y)}{\partial x \partial y}$，在 $F(x,y)$ 二阶连续可导且 $f(x,y)$ 连续时
- ④ $P((X,Y) \in G) = \iint\limits_{G} f(x,y)dxdy$
- ⑤ $P((X,Y) \in L) = 0$，其中 $L$ 是平面上一直线

### 4、边缘密度及性质：
$f_X(x) = \int_{-\infty}^{+\infty} f(x,y)dy = \frac{\partial F(x, +\infty)}{\partial x}$，$f_Y(y) = \int_{-\infty}^{+\infty} f(x,y)dx = \frac{\partial F(+\infty, y)}{\partial y}$

当 $F(x,y) = F_X(x)F_Y(y)$ 或 $f(x,y) = f_X(x)f_Y(y) \Rightarrow X, Y$ 相互独立

### 5、条件密度及性质：
$f_{X|Y}(x|y) = \frac{f(x,y)}{f_Y(y)}$，$f_{Y|X}(y|x) = \frac{f(x,y)}{f_X(x)}$

$F(x|y) = \int_{-\infty}^{x} f_{X|Y}(x|y)dx$，$F(y|x) = \int_{-\infty}^{y} f_{Y|X}(y|x)dy$

## 五、卷积公式

若 $Z = X + Y$，则 $f_Z(z) = \int_{-\infty}^{+\infty} f(x, z-x)dx = \int_{-\infty}^{+\infty} f(z-y, y)dy$

特别地，若 $X, Y$ 相互独立，则

$$f_Z(z) = \int_{-\infty}^{+\infty} f_X(x)f_Y(z-x)dx = \int_{-\infty}^{+\infty} f_X(z-y)f_Y(y)dy$$

## 六、数学期望的定义及性质（用以描述均值）

$E(X) = \sum_{k=1}^{\infty} x_k p_k$（离散）或 $\int_{-\infty}^{+\infty} xf(x)dx$（连续）

特别地，若 $Y = g(X)$，则 $E(Y) = \sum_{k=1}^{\infty} g(x_k)p_k$ 或 $\int_{-\infty}^{+\infty} g(x)f(x)dx$

对两二维随机变量同理，若 $Z = g(X,Y)$，则

$E(Z) = \sum_{i}\sum_{j} g(x_i, y_j)p_{ij}$ 或 $\int_{-\infty}^{+\infty}\int_{-\infty}^{+\infty} g(x,y)f(x,y)dxdy$

**性质**：
- ① 若 $C$ 为常数，则 $E(C) = C$
- ② 线性性质：$E(\sum_{i=1}^{n} C_i X_i + b) = \sum_{i=1}^{n} C_i E(X_i) + b$
- ③ 若 $X, Y$ 相互独立，$E(XY) = E(X)E(Y)$

常见分布的数学期望见一。

## 七、方差的定义及性质（用以描述离对均值的偏离程度）

$D(X) = \sum_{k=1}^{\infty} [x_k - E(X)]^2 p_k$ 或 $\int_{-\infty}^{+\infty} [x - E(X)]^2 f(x)dx = E[(X - E(X))^2]$

$= E(X^2) - [E(X)]^2$，$\sqrt{D(X)}$ 称为标准差/均方差（$\sigma$）

**性质**：
- ① 若 $C$ 为常数，$D(C) = 0$
- ② $D(\sum_{i=1}^{n} C_i X_i) = \sum_{i=1}^{n} C_i^2 D(X_i) + 2C_i C_j \sum_{i \lt j} \text{cov}(X_i, X_j)$
- ③ $D(X) = 0 \iff P(X = C) = 1$，且 $C = E(X)$

常见分布的方差见一。

## 八、变异系数、中心矩与原点矩

变异系数 $C_V = \frac{\sqrt{D(X)}}{|E(X)|}$（$E(X) \neq 0$）用以描述 $X$ 对 $E(X)$ 的相对集中程度

$k$ 阶原点矩 $m_k = E(X^k)$，$k$ 阶中心矩 $\mu_k = E[X - E(X)]^k$

从而有 $E(X) = m_1$，$D(X) = \mu_2$

$$\mu_k = E[X - E(X)]^k = E\sum_{r=0}^{k} C_k^r X^r (-m_1)^{k-r} = \sum_{r=0}^{k} C_k^r m_r (-m_1)^{k-r}$$

## 九、协方差、相关系数的定义与性质

协方差 $\text{cov}(X,Y) = E\{[X - E(X)][Y - E(Y)]\} = E(XY) - E(X)E(Y)$

特别地，$\text{cov}(X,X) = D(X)$

**性质**：
- (1) $\text{cov}(X,Y) = \text{cov}(Y,X)$
- (2) $\text{cov}(X, a) = 0$
- (3) $\text{cov}(aX, bY) = ab \cdot \text{cov}(X,Y)$
- (4) $\text{cov}(X+Y, Z) = \text{cov}(X,Z) + \text{cov}(Y,Z)$
- (5) 若 $X, Y$ 相互独立，则 $\text{cov}(X,Y) = 0$（反向不成立！）

相关系数 $R(X,Y) = \text{cov}(X^*, Y^*) = \frac{\text{cov}(X,Y)}{\sqrt{D(X)}\sqrt{D(Y)}}$，即标准化协方差

**性质**：
- (1) $R(X,Y) = R(Y,X)$
- (2) $|R(X,Y)| \leq 1$
- (3) $|R(X,Y)| = 1 \iff \exists a, b \in R, a \neq 0, \text{s.t. } P(Y = aX + b) = 1$

且若 $R(X,Y) = 1, a \gt 0$；$R(X,Y) = -1, a \lt 0$

当 $R(X,Y) = 0$ 时，仅可说明 $X, Y$ 不线性相关，但仍可有其他相关关系，即无法说明 $X, Y$ 不独立。
