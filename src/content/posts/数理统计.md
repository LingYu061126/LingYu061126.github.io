## 一、抽样分布定理

### 1. 基本概念
- **总体与个体**：研究对象的某项指标全体称为总体，每个单元称为个体。
- **简单随机样本**：来自总体 $X$ 的 $n$ 个相互独立且与总体同分布的随机变量 $X_1, X_2, ..., X_n$。
- **统计量**：样本的函数且不包含未知参数，如样本均值、样本方差。

### 2. 常用统计量
| 统计量 | 定义 | 备注 |
|--------|------|------|
| 样本均值 | $\bar{X} = \frac{1}{n}\sum_{i=1}^{n}X_i$ | $E(\bar{X}) = \mu$ |
| 样本方差 | $S^2 = \frac{1}{n-1}\sum_{i=1}^{n}(X_i-\bar{X})^2$ | $E(S^2) = \sigma^2$ |
| 样本标准差 | $S = \sqrt{S^2}$ | |
| $k$阶原点矩 | $A_k = \frac{1}{n}\sum_{i=1}^{n}X_i^k$ | |
| $k$阶中心矩 | $B_k = \frac{1}{n}\sum_{i=1}^{n}(X_i-\bar{X})^k$ | |

### 3. 三大抽样分布（正态总体）
设 $X_1, X_2, ..., X_n$ 来自正态总体 $N(\mu, \sigma^2)$，则：

| 分布 | 定义 | 表达式 | 性质 |
|------|------|--------|------|
| $\chi^2$分布 | $\chi^2 = \sum_{i=1}^{n}\left(\frac{X_i-\mu}{\sigma}\right)^2$ | $\chi^2 \sim \chi^2(n)$ | 可加性：若$\chi^2_1 \sim \chi^2(m),\chi^2_2 \sim \chi^2(n)$，则$\chi^2_1+\chi^2_2 \sim \chi^2(m+n)$ |
| $t$分布 | $t = \frac{\bar{X}-\mu}{S/\sqrt{n}}$ | $t \sim t(n-1)$ | 对称性，$n \to \infty$时趋近于$N(0,1)$ |
| $F$分布 | $F = \frac{S_1^2/\sigma_1^2}{S_2^2/\sigma_2^2}$ | $F \sim F(n_1-1, n_2-1)$ | 若$F \sim F(m,n)$，则$1/F \sim F(n,m)$ |

### 4. 正态总体下的抽样定理
- $\bar{X} \sim N(\mu, \frac{\sigma^2}{n})$
- $\frac{(n-1)S^2}{\sigma^2} \sim \chi^2(n-1)$
- $\bar{X}$ 与 $S^2$ 相互独立

## 二、参数估计

### 1. 点估计

#### （1）矩估计法
**核心思想**：用样本矩估计总体矩，用样本矩的函数估计总体矩的函数。

**步骤**：
1. 写出总体矩 $E(X^k)$ 关于未知参数的表达式
2. 令样本矩 $A_k = \frac{1}{n}\sum X_i^k$ 等于总体矩
3. 解方程组得参数的矩估计量

**性质**：矩估计具有相合性，但可能不唯一。

#### （2）极大似然估计法
**核心思想**：选择使样本观测值出现概率最大的参数值作为估计值。

**步骤**：
1. 构造似然函数
   - 离散型：$L(\theta) = \prod_{i=1}^{n} P(X_i=x_i;\theta)$
   - 连续型：$L(\theta) = \prod_{i=1}^{n} f(x_i;\theta)$
2. 取对数得 $\ln L(\theta)$
3. 对 $\theta$ 求导并令导数为0
4. 解似然方程得极大似然估计

**性质**：若 $\hat{\theta}$ 是 $\theta$ 的MLE，$g$ 是单调函数，则 $g(\hat{\theta})$ 是 $g(\theta)$ 的MLE。

### 2. 估计量的评选标准

| 标准 | 定义 | 说明 |
|------|------|------|
| **无偏性** | $E(\hat{\theta}) = \theta$ | $\bar{X}$ 是 $\mu$ 的无偏估计；$S^2$ 是 $\sigma^2$ 的无偏估计 |
| **有效性** | 无偏前提下，方差越小越有效 | 比较两个无偏估计时使用 |
| **相合性** | $\hat{\theta}_n \xrightarrow{P} \theta$ ( $n \to \infty$ ) | 样本矩是总体矩的相合估计 |

### 3. 区间估计（数一要求）

**置信区间**：$P(\hat{\theta}_L < \theta < \hat{\theta}_U) = 1-\alpha$，其中 $1-\alpha$ 为置信水平。

#### 单正态总体均值的置信区间

| 情况 | 枢轴量 | 置信区间 |
|------|--------|----------|
| $\sigma^2$已知 | $U = \frac{\bar{X}-\mu}{\sigma/\sqrt{n}} \sim N(0,1)$ | $\left(\bar{X} \pm u_{\alpha/2}\frac{\sigma}{\sqrt{n}}\right)$ |
| $\sigma^2$未知 | $t = \frac{\bar{X}-\mu}{S/\sqrt{n}} \sim t(n-1)$ | $\left(\bar{X} \pm t_{\alpha/2}(n-1)\frac{S}{\sqrt{n}}\right)$ |

#### 单正态总体方差的置信区间
- 枢轴量：$\chi^2 = \frac{(n-1)S^2}{\sigma^2} \sim \chi^2(n-1)$
- 置信区间：$\left(\frac{(n-1)S^2}{\chi^2_{\alpha/2}(n-1)}, \frac{(n-1)S^2}{\chi^2_{1-\alpha/2}(n-1)}\right)$

#### 两个正态总体（数一要求）
- **均值差** $\mu_1-\mu_2$ 的置信区间（方差已知/未知）
- **方差比** $\sigma_1^2/\sigma_2^2$ 的置信区间（用 $F$ 分布）

## 三、假设检验

### 1. 基本概念
- **原假设** $H_0$：通常为“无差异”或“等于某值”的假设
- **备择假设** $H_1$：与原假设对立的假设
- **检验统计量**：用于决策的统计量
- **拒绝域**：使拒绝 $H_0$ 的样本值范围
- **显著性水平** $\alpha$：犯第一类错误的概率

### 2. 两类错误
| 类型 | 定义 | 概率 |
|------|------|------|
| 第一类错误 | 弃真（拒绝真实的 $H_0$） | $P(\text{拒绝}H_0 \mid H_0\text{为真}) = \alpha$ |
| 第二类错误 | 取伪（接受错误的 $H_0$） | $P(\text{接受}H_0 \mid H_0\text{为假}) = \beta$ |

### 3. 假设检验的一般步骤
1. 根据问题提出原假设 $H_0$ 和备择假设 $H_1$
2. 选取合适的检验统计量
3. 给定显著性水平 $\alpha$，确定拒绝域
4. 根据样本观测值计算统计量的值
5. 做出判断：落入拒绝域则拒绝 $H_0$，否则接受 $H_0$

### 4. 正态总体的假设检验（数一要求）

#### 单个正态总体的均值检验
| 条件 | $H_0$ | 检验统计量 | 分布 | 拒绝域 |
|------|---------|------------|------|--------|
| $\sigma^2$已知 | $\mu = \mu_0$ | $U = \frac{\bar{X}-\mu_0}{\sigma/\sqrt{n}}$ | $N(0,1)$ | $\|U\| > u_{\alpha/2}$ |
| $\sigma^2$未知 | $\mu = \mu_0$ | $t = \frac{\bar{X}-\mu_0}{S/\sqrt{n}}$ | $t(n-1)$ | $\|t\| > t_{\alpha/2}(n-1)$ |

#### 单个正态总体的方差检验
| $H_0$ | 检验统计量 | 分布 | 拒绝域 |
|---------|------------|------|--------|
| $\sigma^2 = \sigma_0^2$ | $\chi^2 = \frac{(n-1)S^2}{\sigma_0^2}$ | $\chi^2(n-1)$ | $\chi^2 > \chi^2_{\alpha/2}(n-1)$ 或 $\chi^2 < \chi^2_{1-\alpha/2}(n-1)$ |

#### 两个正态总体的检验
- **均值差检验**（$t$ 检验，分方差相等/不等情形）
- **方差比检验**（$F$ 检验）

## 附：考研数学一重点提示

1. **必考题型**：
   - 求参数的矩估计和极大似然估计（解答题）
   - 验证估计量的无偏性
   - 单个正态总体参数的区间估计（近年填空题出现）

2. **数一特有内容**：
   - 估计量的评选标准（无偏性、有效性、相合性）
   - 区间估计（单总体和双总体）
   - 假设检验（两类错误的理解）

3. **解题技巧**：
   - 矩估计：先求总体矩，再令其等于样本矩
   - 极大似然估计：连续型注意定义域分段情况，离散型注意概率表达式
   - 区间估计：先找枢轴量，再反解不等式
